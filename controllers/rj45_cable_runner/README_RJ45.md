# RJ45 柔性線材插入實驗

這是與原本方塊搬運場景分開的 Webots 實驗。開啟 `worlds/Neura_RJ45_Cable_Assembly.wbt`，按下執行即可讓 UR5e 夾取插頭後側護套、抬起線材、對準路由器網路孔、沿孔軸插入，最後張開夾爪並退回孔外。控制器會在夾爪退回及手臂抬起後檢查插頭位置；只有插頭仍在孔內才印出 `[完成]`。

## 視覺抓取與畫面

夾爪旁已安裝 `pickup_camera`。開啟場景並開始模擬後，相機影像會以浮動視窗顯示在 Webots 的 3D 畫面上；可拖曳視窗或調整大小。若視窗被隱藏，從 Webots 的 **Overlays → Camera Devices** 開啟 `pickup_camera`。

場景沒有取料座；插頭和 36 公分線束直接放在地面。控制器會讓相機巡看六個地面區域，辨識插頭上的橘色標記，從辨識結果計算插頭中心、平面角度及護套抓取點。夾爪斜向接近地面，分段抬升線束，再轉正插頭並插入網路孔。**抓取點不取自插頭的固定起始座標或 Supervisor 真值。**

可在 Webots 中修改 `RJ45_PLUG` 的 `translation` 與繞 Z 軸的 `rotation`，讓插頭以不同位置和方向落在地面，重設模擬後執行。插頭上方的橘色標記需可見；位置也必須落在相機巡看區和 UR5e 的可達範圍。整個 2 × 2 公尺地板並非都能抓取，線材被障礙物卡住或插頭翻面蓋住標記時也可能失敗。若插入後一側夾指被孔口擋住，控制器會先解除夾持並沿孔軸後退，最後檢查插頭是否仍留在孔內。

目前使用 Webots 內建 `Recognition` 提供模擬相機的三維辨識結果；畫面是真正的相機渲染，但辨識不是從 RGB 像素自行訓練或推論的模型。後續若要接近實機，可改用 RGB 影像、深度估測及相機標定。

場景由 `tools/generate_rj45_world.py` 產生，控制器是 `controllers/rj45_cable_runner/rj45_cable_runner.py`。修改線材節數、節長或孔位等參數後，在專案根目錄執行：

```powershell
py -3 tools/generate_rj45_world.py
```

重新執行產生器會覆寫 `.wbt` 場景，包含手動調整的插頭座標；要保留新的預設位置，請同時修改產生器內的插頭 `translation`。

## 模型與限制

- RJ45 插頭有插頭外殼與後側護套；網路孔由有碰撞體的四面殼體圍出空腔。
- 線材由 18 節、每節 2 公分的剛體與球形關節串接，總長約 36 公分，可彎曲及碰撞。這是離散線材近似，並非連續體軟管模型。
- 現有 Robotiq 2F-140 夾爪相對真實 RJ45 過大，因此插頭與孔口約放大兩倍，留出側向張爪及退爪空間。這個場景適合驗證抓取、對位、插入及退出流程，不適合直接量測真實 RJ45 插入力或公差。
- 護套與夾爪、插頭與孔口各用 Webots `Connector` 表示暫時夾持及插入後的卡扣。它們可讓流程穩定重現，但不代表真實的接點導通、卡榫彈性或線材內部應力。若要研究這些量，需要另外建立接觸、材料與電氣模型。

成功時，控制器主控台依序顯示 `[視覺] 插頭位置`、`6. 沿 +X 方向插入 RJ45`、`8. 沿 -X 方向退出夾爪`、`9. 退到孔外後抬高手臂`，最後顯示 `[完成]`。若插頭滑落、偏離孔位，控制器會顯示 `[RJ45 錯誤]` 與原因。
